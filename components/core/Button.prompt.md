Pill-shaped action button; the only button shape in Spekooh — no square/rectangular buttons appear anywhere in the app.

```jsx
<Button variant="primary" size="lg">Pay 500 FCFA</Button>
<Button variant="outline">Open</Button>
<Button variant="ghost" size="sm">Shop</Button>
```

Variants: `primary` (blue gradient, main CTA — "Pay", "Start quiz", "Create free account"), `secondary` (light blue fill), `outline` (bordered, used inside pricing boxes), `ghost` (text-only link style — "Shop", "See all"), `dark` (solid navy, used sparingly). Sizes `sm`/`md`/`lg`. Press state shrinks slightly (scale 0.97) — no color change on press.
